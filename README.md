## 三段式布局（摇摇车是主角）

> 摇摇车形象使用用户提供的透明背景贴纸图 `assets/nomi-car.webp`：车身在黄色弹簧底座上随车速上下颠动，前后轮按车速旋转，周围有音符和星星动效（车轮已单独抠出为 `assets/nomi-car-wheel-*.webp`）。

| 段落 | 内容 | 占比（16:9 横屏） |
|---|---|---|
| **01 摇摇车** | 未投币显示金币 +「投币开摇」；投币后切换成摇摇车，按车速摇动，旁边出现「🏠 不玩了，我要回家」 | 约 93% 屏高，左侧主视觉 |
| **02 实时信息** | 只保留重点：**大号车速 + 大号播放倍速**，加一行当前歌曲、进度条和加大后的车速按钮 | 与选歌栏**等高**（16:9 各约一半），右上 |
| **03 选歌** | 原创歌曲《NOMI 摇摇车》《爸爸的车车叫什么》两张卡片 | 右上信息下方，剩余高度 |

9:10 竖屏时三段从上到下：**摇摇车约 2/3 屏高**（61–64% 屏幕 / 约 2/3 内容区）→ 信息栏约 13–16% → 选歌占剩余。
竖屏信息栏进一步压缩：只保留「大号车速 + 大号播放倍速」、当前歌曲一行和紧凑车速控制，隐藏进度条/时间/卡片副标题。

### 针对浏览器 UI 的「一屏」处理

- 车机/桌面浏览器会占掉顶部地址栏和底部工具栏，所以布局按**实际视口 `100svh`**（小视口高度）计算，而不是屏幕分辨率；
- 车机模式下自动隐藏底栏、压缩顶栏，只保留 NIO 标、已投币和玩法按钮；
- 顶部新增 **「⛶ 全屏」** 按钮：浏览器支持 Fullscreen API 时可隐藏地址栏/工具栏；如果车机浏览器不支持，会提示改用底部安全区；
- **触屏/Android 车机默认自动预留 72px 底部安全区**，避免系统 Dock 遮挡选歌栏；桌面浏览器默认 0；
- 若车机 Dock 更高仍遮挡：打开调试面板把「底部安全区」调到 80–100px（自动记住），或用 URL `?safe=90` 临时指定；桌面预览想全屏可 `?safe=0`；
- 断点按「视口宽高比 + 高度 + 宽度」判断：
  - 宽屏（视口宽高比 ≥ 5:4、高 ≥ 600px、宽 ≥ 900px）：左摇摇车 + 右上信息 + 右下选歌；
  - 竖屏/近方形（宽高比 ≤ 5:4、高 ≥ 760px、宽 ≥ 720px）：三段竖排，摇摇车约 2/3、信息栏最小化；
  - 其他情况（手机/极矮窗口）自动回退为可滚动布局。
- **实测这些视口都一屏放得下**（`scrollHeight === innerHeight`，无横向/纵向溢出）：
  `2560×1250`、`1920×1000 / 940 / 870`、`1680×950`、`1440×900`、`1280×720`、`1024×768`、`900×1000`；
  竖屏 `900×1000` 三段一屏，手机 `390×844` 自动回退为可滚动布局。
  其中 1920×870、1920×940 就是模拟「16:9 屏幕被浏览器 UI 吃掉上下一条」后的视口。

## 投币 → 开摇 → 回家

1. 页面加载后，第一段显示**投币按钮 / 金币**，摇摇车待机。
2. 点「投币开摇」：播放已选歌曲并**单曲循环**，界面切换成摇摇车，摇动节奏跟随车速；同时出现「🏠 不玩了，我要回家」。
3. 点「不玩了，我要回家」：停止播放、进度归零、回到投币台，下次投币继续摇。

摇摇车摇动周期（CSS 变量 `--rock-duration`，按车速实时计算）：

| 车速 | 摇动周期 |
|---|---|
| 0 km/h | 约 2.6 秒/次（慢慢摇） |
| 80 km/h | 约 1.46 秒/次（正常摇） |
| 120 km/h | 约 0.89 秒/次（摇得最欢） |
| ≥140 km/h | 约 0.65 秒/次（封顶） |

播放速度：**0.80×（0）→ 1.00×（80）→ 1.20×（120+）**，浏览器保调变速（`preservesPitch`），只变节奏不变调。

## 车速从哪来

| 方式 | 说明 |
|---|---|
| 滑杆 / 自动巡航 | 默认模拟，0–140 km/h；巡航自动来回踩油门 |
| GPS 测速 | 摇摇车**左上角「GPS」按钮**（已放大）；已有定位权限时页面自动开启并保持，没有权限时点按钮申请；用 `coords.speed` 或位置差分估算，需 HTTPS 或 localhost；隧道/地库自动重试 |
| 原生车机注入 | 原生壳读 CAN/系统车速，每秒调 `NOMI_YAOYAOCHE.setSpeed(kmh)`（最准） |

```js
NOMI_YAOYAOCHE.setSpeed(96);       // 注入真实车速（km/h）
NOMI_YAOYAOCHE.play('nomi');       // 播放/切歌：'nomi' | 'cheche'（旧参数 'family'/'baby' 自动兼容）
NOMI_YAOYAOCHE.stop();             // 不玩了，回家
NOMI_YAOYAOCHE.useGps();           // 打开 GPS 测速
NOMI_YAOYAOCHE.getState();         // 读当前状态
```

### GPS 权限与自动保持

- **页面加载完就主动请求定位权限**（HTTPS/localhost 下会触发浏览器授权弹窗）；
- **已有权限 → 自动开启 GPS 并尽量保持常开**（切回页面、断信号都会自动恢复）；
- **没有权限 / 被拒绝 → 弹出「开启定位权限」提示窗**，可按提示重新请求，或选择「先用滑杆模拟」；
- 摇摇车左上角「GPS」按钮可随时手动开关；地址加 `?gps=0` 可关闭自动请求（仍可手动点按钮开启）；
- **默认是车辆模式（真实车速）**；步行测试是隐藏开关，不在主界面显示；
- 局域网 `http://<IP>:8765` 不是安全上下文，浏览器不会弹定位权限——手机步行测试请用上面的 CloudBase HTTPS 地址。

### 📱 手机步行测试模式

步行只有 4–6 km/h，正常映射下摇摇车几乎不动。打开**车机调试面板**（连点左上角 NIO 标 5 次，或地址加 `?debug=1`），勾选 **「步行测试」** 即可把 GPS 实测车速 **×25** 映射成「等效车速」；也可以用 `?walk=1` 快速开启。默认不勾选 = 车辆模式。

| GPS 实际（步行） | 等效车速 | 播放倍速 |
|---|---|---|
| 2 km/h | 50 km/h | 0.93× |
| 4 km/h | 100 km/h | 1.10× |
| 5 km/h | 125 km/h | 1.18× |
| ≥5.6 km/h | ≥140 km/h（封顶） | 1.20× |

- 信息栏大号数字显示 **「等效车速」**，单位行显示「km/h · 实际 X.X」；
- 来源标签显示 `GPS·步行×25`；
- 灵敏度可在调试面板「倍率」里改（2–100），或 URL `?walk=40`；
- 关闭：调试面板取消勾选，或 `?walk=0`；关闭后立即按真实 GPS 车速映射；
- 原生壳也可调 `NOMI_YAOYAOCHE.setWalkMode(true)` / `setWalkFactor(40)`。

手机测试步骤：手机浏览器打开 CloudBase 地址 → 点「确定访问」→ 允许定位 → 连点 NIO 标 5 次打开调试面板 → 勾选「步行测试」→ 关闭面板 → 开始走。（也可以直接用 `?walk=1`。）若自动权限没弹（部分 iOS 浏览器要求手势），先点「📡 GPS」。

### 使用次数统计

- 投币台下方显示：**本机已被打开 N 次 · 摇过 M 次 · 今日 K 次**；
- 投币后 NOMI 台词会显示「本机第 N 次开摇」；
- 调试面板（连点 NIO 标 5 次 / `?debug=1`）里有更完整的统计：打开次数（今日）、开摇次数（今日）、上次使用时间；
- 统计保存在浏览器 `localStorage`（key `nomi-yaoyaoche-v3`），**仅本机统计，不同设备不汇总**；清除站点数据会重置；
- 需要全量/多设备统计的话，可以再接 CloudBase 数据库或云函数（当前未接后端）。

## 已知限制

- 浏览器无法直接读取车辆 CAN 车速：默认模拟/巡航，GPS 为估算；精确车速需原生壳注入。
- 车机浏览器是否放行定位权限需真车实测；GPS 在隧道/地库会降级。
- 变速依赖 MediaElement；极老旧车机浏览器可能不支持 `preservesPitch`（会变调，但仍可播放）。
- 《NOMI 摇摇车》《爸爸的车车叫什么》均为用户提供的原创歌曲。
