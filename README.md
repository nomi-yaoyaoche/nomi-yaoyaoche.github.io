# NOMI 摇摇车（GitHub Pages 组织站）

蔚来 NOMI 主题的投币摇摇车网页：投币开摇、车速联动摇动/播放、MP3 循环、不想玩就回家。

- 在线体验：https://nomi-yaoyaoche.github.io/
- 备用：https://lzyxczw-cyber.github.io/nio-yaoyaoche/
- 车机适配：GPS 开关在摇摇车左上角，已有定位权限时自动开启并保持；触屏/Android 车机默认自动补偿底部安全区 72px，可在 `?debug=1` 调试面板里调整，或用 `?safe=72` 指定。
